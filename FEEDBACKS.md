# Feedbacks

Unratified user expectations from using N3 as an lgtmd demo. These are not
validated requirements or an accepted implementation plan.

- I expect version history to work with my normal Git commits once lgtmd is set up.
- When I click an old version, I expect to see that version of the docs immediately.
- I expect lgtmd to take care of saving what history needs. I do not want to learn a
  snapshot workflow or prepare special commits just to use version travel.
- If a version cannot be shown, tell me why immediately and make the next step obvious.
- I would like to browse docs already saved in my repository, including their images
  and animations, even if they were created before I adopted lgtmd.
- For demos, I want to jump between versions and clearly see what changed without
  rebuilding the app or switching branches.
